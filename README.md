# John Joshua N. Rojo - Portfolio

A responsive React portfolio built with Vite and Tailwind CSS. The page is composed from the components in `src/components/`, with personal details and editable project examples in `src/data/portfolio.js`.

## Run locally

```sh
npm install
npm run dev
```

## Personalize

Update `src/data/portfolio.js` with your contact email, project descriptions, project URLs, and real project details. The included project cards are prompts, not completed work. Replace them with real projects and screenshots before applying.

Optional assets:

- The About section uses `public/images/jj-transparent.png`.
- The landing page uses the transparent cutout generated from `public/images/john.png` at `public/images/john-transparent.png`.
- Add `public/John-Joshua-Rojo-CV.pdf` and set `resumeUrl` to `/John-Joshua-Rojo-CV.pdf`.
- Set `email` to your contact address to enable the email button.
